# Reporting a vulnerability

!!! warning
    Do not open a public issue for a security problem.

Report it privately through GitHub: on the
[repository](https://github.com/talk2sohail/privoclub), **Security → Report a
vulnerability**. Only the maintainers see it.

Include what you found, the version (`privo version` or `/version`), how to
reproduce it, and what an attacker gains. Test only against your own install,
never anyone else's.

We acknowledge the report, fix it with a test that fails without the fix,
release it, and publish a GitHub security advisory that credits you unless
you prefer not to be named. Please give us a reasonable time to release a fix
before you publish.

The full policy, with the supported versions and what is in scope, is
[SECURITY.md](https://github.com/talk2sohail/privoclub/blob/main/SECURITY.md).
